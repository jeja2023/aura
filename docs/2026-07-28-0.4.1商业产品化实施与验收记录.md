# Aura 0.4.1 商业产品化实施与验收记录

本记录对应 2026-07-28 发布的 Aura 0.4.1。该版本在 0.4.0 基线上完成前侧边栏视口滚动位置保持、商业工作台 Tab 通用胶囊设计对齐、浅色主题高对比度防覆盖修复、ONNX 特征提取模型验证与 Docker 编排加速加固。

---

## 1. 版本变更概要

### 1.1 侧边栏导航与滚动位置保持
- 增加侧边栏导航容器 `scroll` 事件监听与 `sessionStorage` (`aura.sidebar.scrollTop`) 持久化。
- 解决菜单点击和跨页面跳转后侧栏 `scrollTop` 重置归零的问题。
- 自动将当前激活的菜单项 (`.nav-link.is-active`) 保持在视口居中区域 (`scrollIntoView`)。

### 1.2 商业工作台与 UI 交互防覆盖重构
- 参照 `媒体解析平台` 与 `扩展管理` 页面的通用胶囊/卡片式 (Capsule/Pill Tabs) 设计规范，全面重构商业工作台主 View 标签 (`.wb-tab`) 与子视图页签 (`.wb-subtabs button`)。
- 为浅色主题 `--text-muted` 提升对比度至 `#334155`（Slate 700），并对激活标签 (`.is-active`) 赋予主题蓝背景与纯白文字 (`!important`)。
- 提升 CSS 选择器权重至 `.app-content .wb-tabs button.wb-tab`，彻底隔离并解决全站按钮在浅色/白底背景下的白字覆盖与发虚现象。

### 1.3 ONNX 特征模型与 Docker 编排加固
- 验证放置于 `models/osnet_ibn_x1_0.onnx` (268.5MB) 的 OSNet ReID 512 维特征抽取模型，通过 FastAPI 推理服务及 35/35 项单元测试。
- 自动创建并关联外部 `gpu-bridge` Docker 网络。
- 修正 `docker/backend.Dockerfile` 增加华为云 NuGet 镜像源，解决 `dotnet restore` 网络超时问题。
