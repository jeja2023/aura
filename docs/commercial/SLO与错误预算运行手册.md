# SLO 与错误预算运行手册

服务画像定义核心 API 可用率、RPO/RTO、向量/图 P95、积压恢复时间和图重建时间。运行中心按 5 分钟、1 小时、24 小时、7 天展示当前值、趋势、错误预算和最近变更。

告警响应顺序：确认影响租户与链路，关联 trace id，下钻 API/Provider/Inbox/Outbox/通知/向量/图 Worker，检查最近版本/配置/模型/规则变更，再执行有审计的恢复动作。重放、重建、批量删除和配置切换必须走高风险预览及 step-up。

错误预算耗尽后冻结非恢复性发布；维护窗口必须预先批准，不得事后排除故障时间。恢复后记录开始/发现/缓解/恢复时间、根因、数据完整性、重复副作用、积压追平、客户影响和改进责任人。
