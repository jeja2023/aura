## 3. 环境说明

- 沙箱内执行 `.NET restore/build` 和 `pytest` 时会受到 NuGet 网络、临时目录和缓存目录写入权限影响；本次最终验收使用非沙箱执行，并将构建/测试产物放入 `.codex-build` 隔离目录。
- 本机 `docker compose` 子命令不可用，`docker-compose` 可用。现场若 Docker CLI 不支持空格版 Compose 命令，可使用连字符版 `docker-compose` 执行等价操作。
- 本机存在较多 `dotnet` 进程残留，验收期间未批量终止，避免影响可能正在运行的服务。
