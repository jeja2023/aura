# Aura 0.3.1 商业产品化实施与验收记录

本记录对应 2026-07-27 发布的 Aura 0.3.1。该版本是在 0.3.0 商业产品化基线上的维护版本，不改变既有能力分级、现场认证要求或发布门禁结论。

## 变更范围

- 对齐本地与 Docker 环境模板、数据库及缓存连接配置，并补充本地冲突服务清理脚本。
- 修复 PostgreSQL 16 环境中 pgvector 扩展迁移的依赖问题。
- 修复前端 Tab 文本可见性、页面滚动和媒体解析/扩展管理标签样式。
- 同步 .NET、AI、镜像示例、能力矩阵和发布文档的 0.3.1 版本标识。

0.3.0 记录中的浏览器矩阵、真实 ArangoDB、目标规模 pgvector、积压恢复、空环境备份恢复、Linux 离线交付、客户 OIDC、真实通知/Web Push 网关和真机适配器门禁继续有效。只有 `scripts/ops/release-gate.*` 归档目标环境证据后，才能将相应能力标记为通过或 supported。
